# CityCentarWarehouse

Магацин — веб-апликација за евиденција на градежни материјали, приеми/потрошувачка по 6 ламели, и AI скенирање фактури. Целата апликација е еден `magacin.html` фајл.

## AI скенирање фактури (Claude vision)

Скенирањето на фактури има два режими:

1. **Офлајн (Tesseract.js)** — работи веднаш, без интернет по прв пат, без клуч, но е помалку прецизно на фотографии од градилиште (лоша светлина, накривена фактура, кирилична табела).
2. **AI (Claude vision)** — многу попрецизно читање, но бара сопствен мал сервер кој го чува API клучот (клучот НЕ смее да стои во browser-от/HTML-от).

За да го вклучиш AI режимот:

1. Оди во `worker/` папката во ова репо — таму има готов Cloudflare Worker (`index.js` + `wrangler.toml`).
2. Deploy-ирај го со [wrangler](https://developers.cloudflare.com/workers/wrangler/):
   ```bash
   cd worker
   wrangler deploy
   wrangler secret put ANTHROPIC_API_KEY
   # по желба, ограничи го CORS-от само на твојот домен:
   wrangler secret put ALLOWED_ORIGIN   # пр. https://jsholdingwarehouse.com
   ```
3. Земи ја адресата што ја враќа `wrangler deploy` (пр. `https://magacin-ai.<твое-име>.workers.dev`).
4. Во апликацијата: **Поставки → AI скенирање фактури → Адреса на AI сервер** — внеси ја таа адреса и зачувај.
5. Провери со копчето **„Тестирај врска"** во истата секција.

Откако адресата е поставена, скенирањето автоматски преминува на AI режим (без адреса, останува офлајн).
